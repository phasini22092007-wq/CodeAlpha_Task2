# CodeAlpha Task 2: Exploratory Data Analysis

## Project Overview
This project uses Python to explore a book dataset and understand book prices, ratings, and availability.

## Tools Used
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Dataset
The dataset contains 8 books and 4 columns: Title, Price, Rating, and Availability.

## Analysis Performed
- Displayed the first five rows.
- Checked dataset information and missing values.
- Calculated descriptive statistics.
- Created a book price comparison graph.
- Created a book rating distribution graph.

## Key Findings
- Average book price: 30.18
- Lowest book price: 18.20
- Highest book price: 47.82
- Average book rating: 3.875 out of 5
- Missing values: 0

## Conclusion
The project demonstrates basic exploratory data analysis using Pandas and data visualization using Matplotlib.
